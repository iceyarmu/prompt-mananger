# @prompt-optimizer/webdav

WebDAV client package for the Prompt Optimizer project. This package provides WebDAV connectivity for remote file storage and synchronization.

## Installation

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Features

- WebDAV client implementation
- File synchronization
- Remote storage connectivity
- Nextcloud compatibility
