# @prompt-optimizer/editor

Enhanced editor package for the Prompt Optimizer project. This package provides advanced editing capabilities with remote file support.

## Installation

```bash
pnpm install
```

## Development

```bash
pnpm dev
```

## Build

```bash
pnpm build
```

## Features

- Enhanced Markdown editing
- Remote file editing support
- Integration with WebDAV storage
- Advanced editing features

## Architecture

The editor package integrates with the WebDAV package to provide seamless remote file editing capabilities.
