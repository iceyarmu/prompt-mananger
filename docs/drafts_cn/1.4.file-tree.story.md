# Story 1.4: 实现文件树组件

## 状态
草稿

## 故事
**作为**用户，
**我希望**在分层树结构中浏览我的提示文件，
**以便**能够高效地组织和导航我的提示。

## 验收标准
1. 文件树组件显示来自WebDAV根的分层文件夹结构
2. 仅显示.md文件及其父文件夹，带有文件扩展名验证
3. 文件夹的展开/折叠功能，带有平滑的CSS动画（60 FPS）
4. 单击选择，双击打开文件，具有适当的事件处理
5. 突出显示当前选择/活动的文件，带有主题一致的样式
6. 为.md文件显示文件图标，为文件夹显示文件夹图标，使用现有图标系统
7. 组件适合现有左侧栏布局，不破坏响应式设计
8. 树状态在会话期间保持，使用Pinia存储（记住展开的文件夹）
9. WebDAV操作期间显示加载状态，使用现有加载模式
10. 虚拟滚动对超过100个项目的树激活以提高性能
11. WebDAV连接更改时组件自动更新
12. 使用CSS变换的展开/折叠平滑动画
13. 键盘导航支持（箭头键、Enter、空格），具有适当的焦点管理
14. 具有适当的ARIA属性，可供屏幕阅读器使用
15. 搜索/过滤功能，用于快速查找文件，带有防抖输入
16. 响应侧栏调整大小操作，不破坏布局

- 文件过滤：<1000文件客户端，较大树服务器端
