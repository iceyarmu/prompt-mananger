# Story 1.3: 创建WebDAV配置UI

## 状态
草稿

## 故事
**作为**用户，
**我希望**通过UI配置WebDAV连接，
**以便**能够连接到我首选的存储提供商。

## 验收标准
1. 创建配置模态对话框，包含WebDAV连接字段（服务器URL、用户名、密码、连接名称）
2. 实现"测试连接"按钮，带有加载状态和结果反馈
3. 将配置安全地保存在加密的浏览器存储中
4. 支持多个保存的配置文件，可快速切换
5. 在UI中显示当前连接状态（已连接/已断开指示器）
6. 模态对话框遵循现有的模态组件模式和动画
7. 表单验证使用现有的验证工具
8. 样式与当前Tailwind CSS类保持一致
9. 与WebDAVService集成进行连接测试
10. 打开模态时现有UI保持功能正常（非阻塞）
11. 密码字段实现适当的掩码，带有显示/隐藏切换
12. URL验证包括协议检查（首选https）
13. 表单提交在必填字段验证有效之前禁用
14. 为连接失败提供清晰的错误消息
15. 所有异步操作的加载状态

## 开发备注

### 现有模态模式
[来源：packages/ui/src/components/Modal.vue]
项目使用自定义Modal组件：
```vue
<Modal v-model="isOpen">
  <template #title>Title Here</template>
  <!-- Content -->
  <template #footer>
    <!-- Buttons -->
  </template>
</Modal>
```
- 使用Teleport到body
- 有进入/离开过渡
- 使用theme-modal类进行样式

### 使用的Tailwind CSS类
[来源：Modal.vue和现有组件]
- Modal：`theme-modal`，`theme-modal-header`，`theme-modal-content`，`theme-modal-footer`
- 按钮：`theme-button`，`theme-button-primary`，`theme-button-secondary`
- 输入：`theme-input`，`theme-input-error`
- 文本：`theme-text`，`theme-text-secondary`

### Pinia存储模式
[来源：packages/ui/src/composables中的现有存储]
```typescript
import { defineStore } from 'pinia'

export const useWebDAVStore = defineStore('webdav', {
  state: () => ({
    profiles: [] as WebDAVProfile[],
    activeProfile: null as WebDAVProfile | null,
    connectionStatus: 'disconnected' as ConnectionStatus
  }),
  
  actions: {
    async saveProfile(profile: WebDAVProfile) {
      // Implementation
    }
  }
})
```

### 表单验证模式
[来源：现有表单组件]
项目使用响应式验证与计算属性：
```typescript
const errors = reactive({
  url: '',
  username: '',
  password: ''
})

const validate = () => {
  errors.url = !config.url ? 'URL is required' : ''
  // More validation
}
```

### Toast通知使用
[来源：packages/ui/src/components/Toast.vue]
```typescript
import { useToast } from '@/composables/useToast'

const toast = useToast()
toast.success('Connection successful!')
toast.error('Connection failed: ' + error.message)
```

### 安全实施备注
- 使用Web Crypto API进行加密（SubtleCrypto）
- 永远不存储明文密码
- 从浏览器特定数据派生加密密钥
- 在注销/断开时清除凭据
- 每次加密使用安全的随机IV

### 与WebDAVService集成
[来源：Story 1.2 WebDAVService]
```typescript
import { WebDAVService } from '@prompt-optimizer/webdav'

const webdavService = new WebDAVService()
const isConnected = await webdavService.testConnection(config)
```

### localStorage键
遵循storage-keys.ts的现有模式：
- `webdav:profiles` - 加密配置文件列表
- `webdav:active-profile` - 当前活动配置文件ID
- `webdav:credentials:{profileId}` - 每个配置文件的加密凭据
