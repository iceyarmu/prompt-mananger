## 验收标准
1. 编辑器工具栏添加Markdown格式按钮（粗体、斜体、标题、列表、链接、代码块）
2. 分屏视图选项：仅编辑、仅预览、并排视图，带有适当的布局和响应式设计
3. 实时Markdown预览，使用优化的渲染器，带有语法高亮
4. 自动保存功能，500ms防抖，带有保存状态指示器和错误处理
5. 文件更改时的未保存更改指示器，带有视觉反馈
6. 语法高亮用于代码块，使用现有语法高亮库（Prism.js或类似）
7. 标题、列表的智能缩进，带有适当的编辑器行为
8. 预览滚动同步（编辑器滚动时预览也滚动），使用平滑滚动
9. 编辑器具有适当的可访问性标签，支持屏幕阅读器
10. 与现有主题系统集成，支持深色模式
11. 工具栏保持可见，在编辑器区域内固定，不破坏布局
12. 键盘快捷键用于常见操作（Ctrl+B、Ctrl+I等），带有适当的事件处理
13. 拖拽图片上传（可选），带有文件验证和进度指示
14. 文件树中更改时编辑器内容自动更新，使用响应式状态管理
15. 编辑器在大文件（>10MB）上性能优化，使用虚拟化或分页
16. 搜索和替换功能，带有正则表达式支持

### Markdown格式化功能
[来源：现有编辑器功能]
```typescript
export function useMarkdownFormatting(textarea: Ref<HTMLTextAreaElement | null>) {
  const applyFormatting = (type: string, level?: number) => {
    if (!textarea.value) return;
    
    const start = textarea.value.selectionStart;
    const end = textarea.value.selectionEnd;
    const selectedText = textarea.value.value.substring(start, end);
    
    let replacement = '';
    
    switch (type) {
      case 'bold':
        replacement = `**${selectedText || 'bold text'}**`;
        break;
      case 'italic':
        replacement = `*${selectedText || 'italic text'}*`;
        break;
      case 'heading':
        const hashes = '#'.repeat(level || 1);
        replacement = `${hashes} ${selectedText || 'Heading'}`;
        break;
      case 'code':
        replacement = selectedText.includes('\n')
          ? `\`\`\`\n${selectedText || 'code'}\n\`\`\``
          : `\`${selectedText || 'code'}\``;
        break;
      case 'link':
        replacement = `[${selectedText || 'link text'}](url)`;
        break;
    }
    
    // Replace selection and update cursor position
    const newValue = textarea.value.value.substring(0, start) + replacement + textarea.value.value.substring(end);
    textarea.value.value = newValue;
    
    // Set cursor position
    const newCursorPos = start + replacement.length;
    textarea.value.setSelectionRange(newCursorPos, newCursorPos);
    textarea.value.focus();
  };
  
  return { applyFormatting };
}
```

### 自动保存实现
[来源：现有存储模式]
```typescript
export function useAutoSave(
  content: Ref<string>,
  filePath: Ref<string | null>,
  services: Ref<AppServices | null>
) {
  const saving = ref(false);
  const lastSaved = ref<Date | null>(null);
  const hasUnsavedChanges = ref(false);
  
  const debouncedSave = debounce(async () => {
    if (!filePath.value || !services.value || saving.value) return;
    
    try {
      saving.value = true;
      await services.value.storageProvider.putFile(filePath.value, content.value);
      lastSaved.value = new Date();
      hasUnsavedChanges.value = false;
      
      showNotification('File saved', 'success', 2000);
    } catch (error) {
      console.error('Auto-save failed:', error);
      showNotification('Failed to save file', 'error');
    } finally {
      saving.value = false;
    }
  }, 500);
  
  // Watch content changes
  watch(content, (newContent, oldContent) => {
    if (newContent !== oldContent && oldContent !== undefined) {
      hasUnsavedChanges.value = true;
      debouncedSave();
    }
  });
  
  const saveNow = async () => {
    debouncedSave.cancel();
    await debouncedSave();
  };
  
  return {
    saving: readonly(saving),
    lastSaved: readonly(lastSaved),
    hasUnsavedChanges: readonly(hasUnsavedChanges),
    saveNow
  };
}
```

### 滚动同步实现
[来源：编辑器最佳实践]
```typescript
export function useScrollSync(
  editorRef: Ref<HTMLElement | null>,
  previewRef: Ref<HTMLElement | null>
) {
  let isEditorScrolling = false;
  let isPreviewScrolling = false;
  
  const onEditorScroll = () => {
    if (isPreviewScrolling) return;
    isEditorScrolling = true;
    
    nextTick(() => {
      if (editorRef.value && previewRef.value) {
        const editorScrollRatio = editorRef.value.scrollTop / (editorRef.value.scrollHeight - editorRef.value.clientHeight);
        const previewScrollTop = (previewRef.value.scrollHeight - previewRef.value.clientHeight) * editorScrollRatio;
        
        previewRef.value.scrollTo({
          top: previewScrollTop,
          behavior: 'smooth'
        });
      }
      
      setTimeout(() => {
        isEditorScrolling = false;
      }, 100);
    });
  };
  
  const onPreviewScroll = () => {
    if (isEditorScrolling) return;
    isPreviewScrolling = true;
    
    // Similar implementation for preview -> editor sync
  };
  
  return { onEditorScroll, onPreviewScroll };
}
```

### Markdown渲染配置
[来源：性能和安全最佳实践]

```typescript
import MarkdownIt from 'markdown-it';
import Prism from 'prismjs';
import 'prismjs/components/prism-typescript';
import 'prismjs/components/prism-json';
import 'prismjs/components/prism-bash';

const md = new MarkdownIt({
  html: false, // Security: disable HTML
  breaks: true, // Convert '\n' to <br>
  linkify: true, // Auto-convert URL-like text to links
  typographer: true, // Enable smart quotes and other typography
  highlight: (str, lang) => {
    if (lang && Prism.languages[lang]) {
      try {
        return `<pre class="language-${lang}"><code class="language-${lang}">${Prism.highlight(str, Prism.languages[lang], lang)}</code></pre>`;
      } catch (err) {
        console.warn('Syntax highlighting failed:', err);
      }
    }
    return `<pre><code>${md.utils.escapeHtml(str)}</code></pre>`;
  }
});

export const renderMarkdown = (content: string): string => {
  return md.render(content);
};
```

### 键盘快捷键处理
[来源：现有快捷键模式]
```typescript
export function useEditorShortcuts(
  textareaRef: Ref<HTMLTextAreaElement | null>,
  formatFunction: Function,
  saveFunction: Function
) {
  const handleKeydown = (event: KeyboardEvent) => {
    if (event.ctrlKey || event.metaKey) {
      switch (event.key) {
        case 'b':
          event.preventDefault();
          formatFunction('bold');
          break;
        case 'i':
          event.preventDefault();
          formatFunction('italic');
          break;
        case 'k':
          event.preventDefault();
          formatFunction('link');
          break;
        case 's':
          event.preventDefault();
          saveFunction();
          break;
        case 'f':
          event.preventDefault();
          // Open search/replace
          break;
      }
    }
  };
  
  onMounted(() => {
    document.addEventListener('keydown', handleKeydown);
  });
  
  onUnmounted(() => {
    document.removeEventListener('keydown', handleKeydown);
  });
}
```
