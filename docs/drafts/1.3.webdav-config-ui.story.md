# Story 1.3: Create WebDAV Configuration UI

## Status
Draft

## Story
**As a** user,
**I want** to configure my WebDAV connection through the UI,
**so that** I can connect to my preferred storage provider.

## Acceptance Criteria
1. Create configuration modal dialog with WebDAV connection fields (Server URL, Username, Password, Connection name)
2. Implement "Test Connection" button with loading state and result feedback
3. Save configuration securely in encrypted browser storage
4. Support multiple saved profiles with quick switching
5. Display current connection status in UI (connected/disconnected indicator)
6. Modal follows existing modal component patterns and animations
7. Form validation uses existing validation utilities
8. Styling consistent with current Tailwind CSS classes
9. Integration with WebDAVService for connection testing
10. Existing UI remains functional when modal is open (non-blocking)
11. Password field implements proper masking with show/hide toggle
12. URL validation includes protocol check (https preferred)
13. Form submission disabled until required fields are valid
14. Clear error messages for connection failures
15. Loading states for all async operations

## Dev Notes

### Existing Modal Pattern
[Source: packages/ui/src/components/Modal.vue]
The project uses a custom Modal component with:
```vue
<Modal v-model="isOpen">
  <template #title>Title Here</template>
  <!-- Content -->
  <template #footer>
    <!-- Buttons -->
  </template>
</Modal>
```
- Uses Teleport to body
- Has enter/leave transitions
- Uses theme-modal classes for styling

### Tailwind CSS Classes Used
[Source: Modal.vue and existing components]
- Modal: `theme-modal`, `theme-modal-header`, `theme-modal-content`, `theme-modal-footer`
- Buttons: `theme-button`, `theme-button-primary`, `theme-button-secondary`
- Inputs: `theme-input`, `theme-input-error`
- Text: `theme-text`, `theme-text-secondary`

### Form Validation Pattern
[Source: Existing form components]
The project uses reactive validation with computed properties:
```typescript
const errors = reactive({
  url: '',
  username: '',
  password: ''
})

const validate = () => {
  errors.url = !config.url ? 'URL is required' : ''
  // More validation
}
```

### Toast Notification Usage
[Source: packages/ui/src/components/Toast.vue]
```typescript
import { useToast } from '@/composables/useToast'

const toast = useToast()
toast.success('Connection successful!')
toast.error('Connection failed: ' + error.message)
```

### Security Implementation Notes
- Use Web Crypto API for encryption (SubtleCrypto)
- Never store plain text passwords
- Derive encryption key from browser-specific data
- Clear credentials on logout/disconnect
- Use secure random IV for each encryption

### Integration with WebDAVService
[Source: Story 1.2 WebDAVService]
```typescript
import { WebDAVService } from '@prompt-optimizer/webdav'

const webdavService = new WebDAVService()
const isConnected = await webdavService.testConnection(config)
```

### localStorage Keys
Following existing pattern from storage-keys.ts:
- `webdav:profiles` - Encrypted profiles list
- `webdav:active-profile` - Current active profile ID
- `webdav:credentials:{profileId}` - Encrypted credentials per profile
