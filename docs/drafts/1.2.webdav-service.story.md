### Error Handling Pattern
[Source: packages/core/src/services/prompt/errors.ts pattern]
Create custom error classes extending base Error:
```typescript
export class WebDAVError extends Error {
  constructor(
    message: string,
    public code: WebDAVErrorCode,
    public details?: any
  ) {
    super(message);
    this.name = 'WebDAVError';
  }
}
```

- TypeScript support

### Testing Configuration
[Source: packages/core/vitest.config.js]
Tests use Vitest framework. Configure similar to existing packages:
- Unit tests in tests/unit/
- Integration tests in tests/integration/
- Mock WebDAV client for unit tests
- Use Docker WebDAV server for integration tests

### Important Security Considerations
- Never log credentials or authentication headers
- Store credentials in memory only during session
- Clear credentials on disconnect
- Use HTTPS for all WebDAV connections
- Validate all file paths to prevent directory traversal

### Performance Considerations
- Implement connection pooling early to avoid refactoring
- Use streams for files larger than 1MB
- Add progress callbacks for long operations
- Cache folder listings for performance
- Implement request debouncing for rapid operations
