**FileOperationsService (current methods):**
- `read(path: string): Promise<FileContent>` - Reads file from WebDAV or local storage
- `write(path: string, content: string): Promise<FileOperationResult>` - Writes to both storages
- `delete(path: string): Promise<FileOperationResult>` - Deletes from both storages
- `rename(oldPath: string, newPath: string): Promise<FileOperationResult>` - Move/rename operation
- `move(sourcePath: string, destinationPath: string)` - Alias for rename
- `list(dirPath: string): Promise<FileMetadata[]>` - Lists directory contents
