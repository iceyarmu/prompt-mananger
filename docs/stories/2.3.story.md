### Refactoring Performed

- **File**: packages/web/src/stores/index.ts
  - **Change**: Replaced setTimeout with Vue's nextTick for store communication setup
  - **Why**: setTimeout is fragile and non-deterministic for async operations
  - **How**: Using nextTick ensures stores are available before setup, improving reliability

- **File**: packages/web/src/stores/types.ts
  - **Change**: Added type-safe event definitions with StoreEventMap
  - **Why**: Loose string-based events are error-prone and lack IDE support
  - **How**: TypeScript mapped types provide compile-time safety and better developer experience

- **File**: packages/web/src/stores/communication.ts
  - **Change**: Implemented safeWatch wrapper for all watchers
  - **Why**: Unhandled errors in watchers could crash the application silently
  - **How**: Error boundary pattern catches and logs errors while maintaining app stability

- **File**: packages/web/src/stores/persistence.ts
  - **Change**: Enhanced version checking with legacy format support and corruption recovery
  - **Why**: Better handling of edge cases and corrupted state
  - **How**: Graceful degradation with automatic cleanup of corrupted data

- **File**: packages/web/src/utils/credentialManager.ts
  - **Change**: Added comprehensive input validation for credential storage
  - **Why**: Security hardening to prevent injection attacks and storage overflow
  - **How**: Validates key format, credential structure, and value sizes before storage
